# Frontend

App mobile em React Native com Expo. As decisões de arquitetura, o passo a passo para rodar e o fluxo das telas estão no [README da raiz](../README.md), na seção **Frontend** de "Como rodar".

Resumo:

```bash
yarn
yarn start   # i para iOS, a para Android, ou QR code no Expo Go
```

A API precisa estar rodando em `http://localhost:3000` (veja o README da raiz).
